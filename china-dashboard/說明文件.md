# KIRII Dashboard 數據說明

## 一、HKD/RMB 匯率

### 顯示內容
- **日期** — 中國銀行發佈牌價嘅日期同時間
- **匯買** — 現匯買入價（100港幣兌幾多人民幣，銀行買入港幣嘅價格）
- **匯賣** — 現匯賣出價（100港幣兌幾多人民幣，銀行賣出港幣嘅價格）
- **中行折算價** — 中國銀行嘅折算參考價
- **曲線圖** — 過去一年嘅人民幣匯率中間價走勢（100港幣 = ? 人民幣）

### 數據來源
- 匯買、匯賣、中行折算價：**中國銀行外匯牌價**（https://www.boc.cn/sourcedb/whpj/）
- 中間價曲線圖：**中國貨幣網 人民幣匯率中間價**（https://www.chinamoney.com.cn/chinese/bkccpr/）

### 更新頻率
- 中國銀行喺每個工作日會多次更新牌價（通常朝早開始，全日持續更新）
- 中間價每個工作日上午9:15左右發佈一次

## 二、Galvanized Steel Coil 鍍鋅板卷價格

### 顯示內容
- 6條線分別代表唔同規格同地區嘅鍍鋅板卷價格（單位：元/噸）：
  - 🔴 有花：1×1219×C：樂從鎮：鞍鋼
  - 🔵 無花：1×1250×C：樂從鎮：鞍鋼
  - 🟠 無花：1×1250×C：濟南：寶鋼
  - ⚫ 無花：1×1250×C：廣州：鞍鋼
  - 🟢 無花：0.8×1250×C：樂從：鞍鋼
  - 🟣 無花：0.8×1250×C：廣州：鞍鋼
- 圖表右側顯示每條線嘅最新價格

### 數據來源
- **Mysteel 我的鋼鐵網**（透過 Google Sheets 同步）
- 原始數據由 Mysteel 每日發送電郵附件，經 GAS 腳本自動匯入 Google Sheets「鍍鋅板卷價格」工作表

### 更新頻率
- 每個工作日更新一次（Mysteel 發送數據後自動處理）

### 更新頻率
- 每個工作日更新一次

## 數據更新流程

```
Mysteel / cnal.com / boc.cn
        ↓
   自動抓取數據
        ↓
   Google Sheets 儲存
        ↓
   Vercel API 讀取
        ↓
   香港 PC 定期取得 JSON
        ↓
   dashboard.html 自動重新生成
        ↓
   中國側瀏覽器打開即可查看
```

## 備註
- 所有價格僅供參考，實際交易請以各機構官方報價為準
- 如果數據冇更新，請聯繫香港辦公室確認數據取得腳本係咪正常運行
