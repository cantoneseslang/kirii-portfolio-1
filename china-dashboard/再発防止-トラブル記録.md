# china-dashboard トラブル記録と再発防止

このファイルは、**静的 HTML（`dashboard.html`）と Vercel の portfolio 表示が食い違う・同期が効かない**といった事例の整理用です。次に不具合を疑うときは、ここから参照してください。

---

## 1. 問題の整理（今回の事象）

| # | 見え方・症状 | 影響 |
|---|----------------|------|
| A | **`Sync targets (0):` のあと、共有フォルダに `dashboard.html` がコピーされない** | U:/ Q: 側で古い HTML のまま |
| B | **cmd 先頭に `'?' は内部コマンドではありません` や変な文字列が出る** | `set REMOTE_*` が実行されず、A と同じ結果になりやすい |
| C | **portfolio は 5/7 なのに、file:// の china-dashboard は 3/31 のまま** | 見ているパスが違う、または fetch 失敗・未実行 |
| D | **portfolio と表・グラフの内容が違う** | 取得クエリ不一致（特に鋼材の履歴件数） |
| E | **HKD の「前一个工作日」など表示ルールを portfolio に寄せすぎた** | 依頼は「HKD レートグラフの Y 軸の反転」のみにすべきだった → **余計な表示変更は戻した** |

---

## 2. 原因

### A・B：同期先 0 件・bat が壊れる

- **`fetch-data.bat` を UTF-8（BOM なし/あり）＋日本語コメント＋`chcp 65001`** のまま **繁体字環境の `cmd.exe`** で実行すると、**行の解釈が壊れ**、`%~dp0` や `set "REMOTE_1=..."` が正しく動かないことがある。
- その結果、PowerShell に渡る **`-RemoteDirs` が空**になり、`fetch-data.ps1` 内の **「Sync targets (0)」** になり、**3 フォルダへコピーされない**。

### C：日付が極端に古い

- **本番 API**（例: `/api/dashboard/hkd-rmb-rate`）は新しい日付を返しているのに、ブラウザの `file://` が古い場合は典型的に次のいずれか：
  1. **`fetch-data.bat` が最後まで成功しておらず**、古い `dashboard.html` のまま
  2. **開いているパスが同期の対象外**（下記「フォルダ名の取り違え」）
  3. **ブラウザ・キャッシュ**（Ctrl+F5 やファイルを閉じてから開き直し）

### D：portfolio とデータが一致しない

- **鋼材 API**は、portfolio（`SteelPriceChartCard`）が **`pointLimit=2000`** で取っている。
- china-dashboard の `fetch-data.ps1` が **`pointLimit=365`** のままだと、**比較表（本月初・年初など）とグラフの参照範囲が狭くなり**、portfolio と**別物**になる。
- **データの取り方自体**：PC が直接 BOC/シートに行くのではなく、**もともと Vercel の URL（`/api/dashboard/...`）から JSON を取得**している。ここは変更の有無に関係なく同じ経路。

### E：表示仕様の取り違え

- **依頼は「HKD レートの Y 軸の上下反転」（portfolio / china-dashboard のグラフ）のみ**に寄せる。
- 「香港の今日を基準に前一个工作日を揃える」「古いデータの注意文」などは、**依頼なしで入れない**（入れた場合は戻す）。

### フォルダ名の取り違え（C の強化要因）

- 同期・運用で想定しているのは **`china-dashboard`（ハイフン）**。
- **`china_dashboard`（アンダースコア）** は **別フォルダ**。bat の `REMOTE_*` は**ここには向いていない**。

---

## 3. 対策（実装・運用）

### バッチ（`.bat`）

- **`fetch-data.bat` / `fetch-data-silent.bat`** は **ASCII のみ**（日本語コメント禁止、`chcp 65001` を bat に書かない）。
- 同期先は bat 内の次の 3 つ（環境に合わせて編集可）：
  - `U:\china-dashboard`
  - `U:\Purchase\china-dashboard`
  - `Q:\Purchase\china-dashboard`

### PowerShell（`fetch-data.ps1`）

- **鋼材**: `seriesLimit=6` **`&pointLimit=2000`**（portfolio と同じ）。
- **アルミ**: `pointLimit=2000`（従来どおり portfolio と合わせる）。
- 実行後ログで **`Vercel API hkd-rmb-rate: date=...`** を確認できるようにしてある。

### HKD グラフ（china-dashboard）

- **変更は Y 軸のみ**：`min:85, max:93`, `reverse:true`（portfolio の見え方に合わせた反転）。
- 表の **`前一个工作日` は `rate.date` 基準の既存ロジック**（portfolio の React 版とは別。依頼がない限りここを portfolio に揃えない）。

### API（Vercel）

- HKD / 履歴 / 鋼材 / アルミの一部ルートは **`Cache-Control: no-store`** 寄りにし、**取り込み時に古い CDN 応答が返る確率を下げる**（詳細は該当 `app/api/dashboard/**/route.ts`）。

### BOC パース（`lib/hkd-rmb-rate.ts`）

- 中行ページの「港币」行が列数変化しても、**行内の `YYYY/MM/DD` を拾う**ようにして**取りこぼしを減らす**。

## 4. 再発防止チェックリスト（fetch のたび）

実行後、次を**順に**確認する。

1. **cmd にエラーが出ていないか**（`?` や `'dp0'` などが出たら **bat をいじっていないか・UTF-8 で日本語を入れていないか**を疑う）。
2. **`Sync targets (3):` と、パスが 3 行出ているか**。
3. **`OK: Copied+Verified ... dashboard.html`** が **最大 3 回**（各同期先ごと）出るか。
4. **`sync-proof-local.txt`** と、必要なら各先の **`sync-proof.txt`** の更新時刻。
5. ブラウザは **`U:\Purchase\china-dashboard\dashboard.html` のように、ハイフンのパス**を開いているか（アンダースコアの別フォルダを見ていないか）。
6. **portfolio の鋼材・アルミの日付**と、`Data last fetched` や表の最新日が**大きくずれていないか**。

## 6. メンテ時の注意

- **「表示だけ portfolio に合わせる」**の依頼がない限り、`dashboard-template.html` の **表ロジック・文言を変えない**。
- **bat に日本語や特殊文字を足さない**（メモ帳で UTF-8 保存すると再現しやすい）。
- 同期先フォルダを変えたら **`fetch-data.bat` と `fetch-data-silent.bat` の両方**の `REMOTE_*` を揃える。
